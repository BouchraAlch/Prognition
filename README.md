# Prognition

**Your AI Workspace for Learning & Productivity**

Prognition is a learning and productivity web application that helps
users organize their study materials and learn more effectively with the
help of AI.

Users can create subjects, organize each subject into topics, and write
notes inside each topic. An AI assistant can then help them study using
the content of their notes.

## Features

-   **Organized learning:** Create subjects and divide them into topics.
-   **Notes:** Add and manage lesson notes inside each topic.
-   **AI assistant:**
    -   Summarize lesson notes.
    -   Generate quizzes based on the lesson.
    -   Answer questions using the learning material provided in the
        notes.
-   **Authentication:** Sign up and log in using Google or an email and
    password.

## Tech Stack

-   **Frontend:** Next.js, React, TypeScript, Tailwind CSS
-   **Backend / AI:** FastAPI and Python
-   **Database and authentication:** Supabase
-   **AI capabilities:** AI-powered summarization, quiz generation, and
    question answering based on lesson notes

## Project Purpose

Prognition was developed as a portfolio project to demonstrate
full-stack web development, authentication, database integration, and
the practical use of AI in an educational application.
